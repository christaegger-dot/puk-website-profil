# Illustration (Muster D)

Eigene Linienzeichnung einer Szene oder Metapher, die man ohne Erklärung wiedererkennt (`.puk-vis-scene`). Beschriftet wird mit Sätzen aus Sicht von Menschen als HTML-Text, nie mit Namen von Bildteilen; keine Liste zum Entschlüsseln. Regeln: Abschnitt «Visuelle Wissensvermittlung», «Ein Bild, eine Idee» (Profilentscheid 10.10.2026). Beispiel: «Ein freier Abend» (Musterinhalt, fachliche Freigabe ausstehend).

Fremde Bilder ohne freigegebene Quelle bleiben ein abstrakter Platzhalter mit sichtbarem Bildquelle- und Freigabestatus (`.puk-vis-illu`, Beispiel im Psychoedukations-Starter).

Live-Muster aus `templates/website/longform/visualisierungsmuster.html` mit `visual-patterns.css` (nach `components/bundle.css` laden). Auswahl: Abschnitt «Visuelle Wissensvermittlung»; Umsetzung: «Visualisierung umsetzen». Jede Figur trägt `data-visual-id` (Eintrag im Visualisierungsplan) und `data-visual-type`; eigene Darstellungen sind als «Eigene didaktische Darstellung» gekennzeichnet.

**Drei Erklärungsebenen (08.10.2026):** Kernaussage (`p.puk-vis-kern`), kurzer Erklärtext (`p.puk-vis-short`), wo sinnvoll Vertiefung (`details.puk-vis-more`).
