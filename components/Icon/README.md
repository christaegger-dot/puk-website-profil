# Icon

Lucide als gekennzeichneter Ersatz, immer in Textfarbe. Grössen 16, 20, 24 px.

Das CD-Manual definiert kein eigenes Icon-Set; verfügbar sind 13 lokal mitgelieferte Lucide-Glyphen (Abschnitt «Icons» im README).

```jsx
<Icon name="arrow-right" size={20} />
```

Namen in Lucide-Schreibweise (kebab-case). Grössen 16, 20 oder 24 px, Farben nur aus der Hauspalette. Icons stützen Text, ersetzen ihn nicht.

Typen: `components/Icon/Icon.d.ts`. Aufruf über `window.PUKWeb.Icon`.
