# Bildwelt

Würde, Alltag und Handlungsfähigkeit — keine Rekonstruktion fehlender Manual-Tafeln.

Foundation-Karte aus dem PUK Zürich Design System 1.10.1 (Vollsystem), keine Komponente im Bundle.

Abgeleitete Bildrichtung: natürlicher Alltagskontext, Würde und Handlungsfähigkeit, ruhige Ausschnitte.

- **Einsatz:** Briefing für Fotografie und Bildauswahl, solange keine amtlichen Bildwelt-Tafeln vorliegen.
- **Pflicht:** Einwilligung, Persönlichkeitsrechte, Alternativtext und Bildnachweis.
- **Vermeiden:** Blaufilter, inszenierte Verzweiflung, psychiatrische Symbolklischees.
- **Status:** Abgeleitet, nicht als amtliche Manual-Vorgabe belegt; bewusste Ergänzung im Gestaltungsspielraum, keine Rekonstruktion fehlender Seiten.

Für Websites gesammelt im Abschnitt «Visuelle Wissensvermittlung» (Bildsprache, Fotos); dort auch die Regeln für Illustrationen.
