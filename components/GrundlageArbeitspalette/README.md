# Arbeitspalette

Die Marke gibt Freiheit — die Publikation begrenzt sie vor Produktionsbeginn bewusst.

Foundation-Karte aus dem PUK Zürich Design System 1.10.1 (Vollsystem), keine Komponente im Bundle.

Die Arbeitspalette begrenzt die Farbfreiheit der Marke bewusst für eine konkrete Publikation, bevor die Produktion beginnt.

- **Einsatz:** Zu Beginn jeder grösseren Publikation die verwendeten Stufen festlegen.
- **Pflicht:** Nur Schattierungen der Hausfarben; Signalfarben punktuell.
- **Status:** Arbeitsmethode des Systems; das Arbeitsheft ist die Referenzimplementierung.
