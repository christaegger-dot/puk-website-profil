# Checkbox

Natives Kontrollkästchen, direkt gestaltet. Fokus vom Element selbst.

Quadratische Mehrfachauswahl; angekreuzt in PUK-Blau gefüllt. Die Beschriftung gehört zum Klickziel.

```jsx
<Checkbox label="Ich habe die Datenschutzerklärung gelesen." />
```

Typen: `components/Checkbox/Checkbox.d.ts`. Aufruf über `window.PUKWeb.Checkbox`.
