# Diagramme

Prinzip: Sachzeichnungen, Kreisläufe als Kreis, Pfeilring innerhalb der Felder — Masse als Beispiel.

Foundation-Karte aus dem PUK Zürich Design System 1.10.1 (Vollsystem), keine Komponente im Bundle. **Gilt für Word- und PowerPoint-Diagramme.** Auf Websites gelten die Muster A–K und die Web-Diagrammregeln (Abschnitt «Visualisierung umsetzen», Profilentscheid 06.10.2026).

Diagramme als Sachzeichnungen: weisse Felder mit Haarlinie auf `--surface-structure`, Pfeile in Blau 1,5 px, Arial, höchstens ein blaues Akzentfeld.

- **Einsatz:** Abläufe, Kreisläufe und Zusammenhänge in Dokumenten und Folien.
- **Pflicht:** Kreisläufe als Kreis; Pfeilring innerhalb der Felder; `role="img"` mit beschreibendem `aria-label`.
- **Vermeiden:** Schatten, Verläufe, Symbolik; SVG-Text verkleinern statt das Feld zu erhöhen.
- **Status:** Bewährte Ergänzung, keine Manual-Vorgabe; die Masse auf der Karte sind ein gerechnetes Beispiel, verbindlich ist die Beziehung.
