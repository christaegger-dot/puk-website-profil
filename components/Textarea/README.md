# Textarea

Mehrzeilige Eingabe mit denselben Zuständen wie Input.

Für Freitext wie Nachrichten. Reflexionseingaben auf psychoedukativen Seiten standardmässig nicht speichern.

```jsx
<Textarea rows={5} placeholder="Ihre Nachricht" />
```

Typen: `components/Textarea/Textarea.d.ts`. Aufruf über `window.PUKWeb.Textarea`.
