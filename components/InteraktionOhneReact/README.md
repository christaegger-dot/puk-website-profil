# Interaktion ohne React

Akkordeon, Reiter, Dropdown-Menü, Dialog, Button, Listenfilter und Abschnittssuche als HTML-Markup mit `components/bundle.css` und `components/interaktion.js` – für statische Websites. Ohne Skript bleiben alle Inhalte sichtbar. Ein Sprunglink setzt den Fokus sichtbar auf sein Ziel. Markup und Optionen: `templates/website/interaktion/README.md`; Regeln: Abschnitt «Interaktionskonzept».
