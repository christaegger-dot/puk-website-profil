# Interaktion ohne React

Akkordeon, Reiter, Dropdown-Menü, Dialog und Button als HTML-Markup mit `components/bundle.css` und `components/interaktion.js` – für statische Websites. Ohne Skript bleiben alle Inhalte sichtbar. Markup und Optionen: `templates/website/interaktion/README.md`; Regeln: Abschnitt «Interaktionskonzept».
