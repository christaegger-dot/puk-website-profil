# Switch

Ein/Aus mit sofortiger Wirkung. Die einzige Pille im System.

Einstellung mit sofortiger Wirkung, etwa «Hoher Kontrast» – die einzige Pillenform im System. Gehört die Auswahl zu einem Formular, das erst mit «Senden» wirkt: `Checkbox`.

```jsx
<Switch label="Benachrichtigungen" defaultChecked />
```

Typen: `components/Switch/Switch.d.ts`. Aufruf über `window.PUKWeb.Switch`.
