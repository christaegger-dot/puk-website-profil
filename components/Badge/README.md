# Badge

Kurzes Statuslabel in kleinen Versalien.

Gelb und Rot sind die Signalfarben des CD – nur für Warnungen und Fehler. Die Bedeutung steht immer im Text des Labels, nie nur in der Farbe.

```jsx
<Badge tone="warning">Wartezeit</Badge>
```

Typen: `components/Badge/Badge.d.ts`. Aufruf über `window.PUKWeb.Badge`.
