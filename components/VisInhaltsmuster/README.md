# Inhaltsmuster

Acht Inhalts- und vier Anwendungsmuster: erst den Job klären, dann das Muster wählen. Regeln: Abschnitt «Anwendungs- und Inhaltsmuster».

Aus der Pattern-Bibliothek der Claude-Design-Schicht (PUK Zürich Design System 1.10.1). Register: `claude-design/patterns.json`. Regel: «Nur Muster verwenden, die dem Kommunikationsziel dienen. Metapher vor Diagramm, Diagramm vor Container.» Die Links auf die Anwendungsmuster zeigen hier auf den Abschnitt; die Referenzseiten liegen unter `templates/website/applications/`.
