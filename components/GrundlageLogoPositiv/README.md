# Logo positiv

Statisches Logo, deutsch – Standard auf hellen Flächen; englische Logos nicht enthalten.

Foundation-Karte aus dem Website-Profil (keine Komponente im Bundle).

Das Logo «Perspektiven», statisch und positiv: Schwarz auf Weiss als Standardanwendung.

- **Einsatz:** Auf Websites und in Browser-Anwendungen immer im Seitenkopf (Profilentscheid 08.10.2026).
- **Pflicht:** `PUK_Logo_statisch_positiv_de.svg`; in der Regel oben links; Wortmarke nie ohne Symbol.
- **Logo-Link:** Name beginnt mit dem Logotext, z. B. «Psychiatrische Universitätsklinik Zürich – Startseite» (WCAG 2.5.3, 11.10.2026). Mit erzwungenen Farben im dunklen Schema kehrt `bundle.css` das Logo hell.
- **Vermeiden:** Nachgezeichnete oder rekonstruierte Logos.
