# Feste Referenz für den Selbsttest

`node tools/gate.mjs --selftest` prüft das Gate an dieser Referenz, nicht an den Inhalten der jeweiligen Website. So läuft der Selbsttest im Starter und in jeder Kopie gleich.

Die Dateien sind eine Kopie von `site.config.json` und `content/` des Psychoedukations-Starters (Stand 08.10.2026; Planfeld `resonance` ergänzt am 10.10.2026). Nicht bearbeiten. Wird das Gate geändert, Referenz und Mutationen in `contract.js` gemeinsam anpassen.
