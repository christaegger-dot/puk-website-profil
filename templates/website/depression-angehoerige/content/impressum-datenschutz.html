Datenschutz

Diese Website erhebt so wenige Daten wie möglich.

Keine Cookies, keine Auswertung
Die Website setzt keine Cookies und verwendet keine Dienste, die Besuche auswerten oder Werbung zeigen.
Keine Dienste anderer Anbieter
Schriften, Bilder und Skripte liegen auf demselben Server wie die Seiten. Beim Lesen gehen keine Daten an andere Anbieter.
Protokolle beim Betrieb
Die Website wird über den Dienst Netlify (Netlify, Inc., USA) ausgeliefert. Netlify speichert beim Aufruf einer Seite technisch notwendige Angaben, zum Beispiel IP-Adresse, Zeitpunkt, aufgerufene Seite und Browser, und braucht sie für einen sicheren Betrieb. Diese Angaben können auch in den USA bearbeitet werden.
E-Mail an die Fachstelle
Wenn Sie der Fachstelle schreiben, verwendet sie Ihre Angaben, um Ihnen zu antworten. Gewöhnliche E-Mails sind nicht durchgehend verschlüsselt; schreiben Sie nur, was Sie auf diesem Weg mitteilen möchten.
Links auf andere Websites
Wenn Sie einem Link auf eine andere Website folgen, gelten dort deren Regeln zum Datenschutz.
