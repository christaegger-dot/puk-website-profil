# Schlanker Website-Starter

Vier Seiten: Übersicht, eine Themenseite, Impressum und Datenschutz sowie 404. Keine vorgegebenen klinischen Themen, Krisenblöcke oder erfundenen Freigaben. Inhalte und Prüfbericht sind Eingabevorlagen; die Produktion bleibt gesperrt, bis das neue Projekt tatsächlich geprüft ist.

Im Repository-Stamm ein eigenes Projekt erzeugen:

```sh
npm run neu -- mein-thema --titel "Mein Thema"
```

Der Befehl legt `websites/mein-thema/` mit lokalen Logo-Dateien an, passt die Pfade an und baut bereits die Vorschau. Er überschreibt keinen vorhandenen Ordner. Die zentralen Build- und Prüfwerkzeuge werden nicht kopiert. Die bisherige ausführliche Musterwebsite bleibt als Gestaltungsreferenz verfügbar.
