Datenschutz

Diese Website erhebt so wenige Daten wie möglich. Sie unterliegt dem Bundesgesetz über den Datenschutz (DSG) der Schweiz.

Keine Cookies, keine Auswertung
Die Website setzt keine Cookies und verwendet keine Dienste, die Besuche auswerten oder Werbung zeigen. Sie bindet keine Inhalte sozialer Netzwerke ein.
Keine Dienste anderer Anbieter
Schriften, Bilder und Skripte liegen auf demselben Server wie die Seiten. Beim Lesen gehen keine Daten an andere Anbieter.
Protokolle beim Betrieb
Die Website wird über den Dienst Netlify (Netlify, Inc., USA) ausgeliefert. Netlify speichert beim Aufruf einer Seite technisch notwendige Angaben, zum Beispiel IP-Adresse, Zeitpunkt, aufgerufene Seite und Browser, und braucht sie für einen sicheren Betrieb. Diese Angaben können auch in den USA bearbeitet werden. Netlify nennt dafür unter anderem Standardvertragsklauseln und das Swiss-U.S. Data Privacy Framework. Weitere Angaben enthält die Datenschutzerklärung von Netlify.
Frühere Einträge im Browser
Eine frühere Fassung dieser Website bot ein Werkzeug für persönliche Einträge an. Falls Sie es genutzt haben, können Ihre Einträge noch lokal im Browser auf Ihrem Gerät liegen. Sie wurden nicht an die Website übertragen. Entfernen können Sie sie in den Einstellungen Ihres Browsers.
E-Mail an die Fachstelle
Wenn Sie der Fachstelle schreiben, verwendet sie Ihre Angaben, um Ihnen zu antworten. Gewöhnliche E-Mails sind nicht durchgehend verschlüsselt. Schreiben Sie nur, was Sie auf diesem Weg mitteilen möchten.
