# Verstehen. Unterstützung finden. Auf sich achten.

Wenn ein nahestehender Mensch mit Borderline lebt, kann vieles schwierig werden. Hier finden Sie Hilfe für den Alltag und Ihre eigene Entlastung.

**Worum es hier geht:** Zweck, Grenzen und passende Einstiege dieser Website kennenlernen.

**Das können Sie mitnehmen:** Sie können ein Anliegen wählen und wissen, wo Sie Information, eigene Beratung oder akute Hilfe finden.
