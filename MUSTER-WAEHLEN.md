# Welches Muster passt zu meinem Inhalt?

Zuerst die Leserfrage klären. Eine Darstellung einsetzen, wenn sie etwas besser erklärt als Text. Die Beispiele zeigen Gestaltungsmuster und ersetzen keine fachliche Prüfung.

| Was soll verständlich werden? | Passendes Muster | Beispiel |
| --- | --- | --- |
| Eine kurze Aussage oder wenige Schritte erklären | Gut gegliederter Text | [Ansehen](templates/website/profilbeispiel/) |
| Wechselwirkungen und Wiederholungen verstehen | Kreislauf | [Ansehen](templates/website/longform/visualisierungsmuster.html#muster-kreislauf) |
| Einen zeitlichen Ablauf nachvollziehen | Prozesspfad | [Ansehen](templates/website/longform/visualisierungsmuster.html#muster-pfad) |
| Zwei Möglichkeiten anhand gleicher Merkmale vergleichen | Vergleich | [Ansehen](templates/website/longform/visualisierungsmuster.html#muster-vergleich) |
| Zwischen nachvollziehbaren Wegen wählen | Entscheidungsweg | [Ansehen](templates/website/longform/visualisierungsmuster.html#muster-entscheidung) |
| Erklären, wie etwas entsteht | Modell in Schritten | [Ansehen](templates/website/longform/erklaermuster.html#muster-g) |
| Zwei gleichzeitig wichtige Anliegen zeigen | Spannungsfeld | [Ansehen](templates/website/longform/erklaermuster.html#muster-h) |
| Beziehungen und Zuständigkeiten ordnen | Beziehungskarte | [Ansehen](templates/website/longform/erklaermuster.html#muster-i) |
| Übergänge statt starrer Kategorien erklären | Kontinuum | [Ansehen](templates/website/longform/erklaermuster.html#muster-j) |
| Mehrere Ebenen eines Sachverhalts unterscheiden | Schichtenmodell | [Ansehen](templates/website/longform/erklaermuster.html#muster-k) |
| Eine Alltagssituation anschaulich machen | Illustration | [Ansehen](templates/website/longform/visualisierungsmuster.html#muster-illustration) |
| Zusätzliche Informationen auf Wunsch anbieten | Akkordeon und Reiter | [Ansehen](templates/website/interaktion/beispiel.html) |
| Den passenden Kontakt oder nächsten Schritt finden | Anwendungsmuster | [Ansehen](ui_kits/website/) |

Telefonnummern sind erlaubt. Krisenkontakte nur nach bewusstem Themenentscheid ergänzen.
